# DevOps To-Do API

Projeto desenvolvido para as atividades formativas da disciplina de DevOps.

## Objetivo

Desenvolver uma API simples para gerenciamento de tarefas,
aplicando conceitos de Git, GitHub, CI/CD e Docker.

## Tecnologias

- Python
- Flask
- Pytest
- Git
- GitHub
- GitHub Actions
- Docker

## Funcionalidades

- Criar tarefas
- Listar tarefas
- Concluir tarefas
- Excluir tarefas
